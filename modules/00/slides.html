Course overview

Course description

  • This course covers principles and practice of AI coding agents in software engineering.
  • Topics include
    • Foundations of generative AI and agentic systems
    • Directing agents toward engineering goals
    • Evaluation and testing of AI-generated code
    • Design and construction of custom agent systems

Course description

  • Topics cont’d
    • Security and oversight of autonomous agents
    • Integration of agents into software development processes
    • and professional, legal, and economic considerations
  • Includes a substantial hands-on project

Learning outcomes

  1. Understand the basic working principles and history of LLMs (Large Language Models) and agents, including the agentic loop, retrieving data, and incorporating tools.
  2. Apply effective prompting practices to direct coding agents toward a working solution, using a structured lifecycle approach.

Learning outcomes

  1. Critically evaluate AI-generated code and agent output, identifying and fixing hallucinated output and comparing performance using industry benchmarks.
  2. Integrate coding agents into real software engineering workflows while applying necessary security controls and licensing considerations.
  3. Design, build, and deploy a complete application using coding agents or design a custom coding-agent system end-to-end.

In summary

  • Focus on using AI coding agents effectively vs. “vibe-coding”
  • Provide a level of understanding beyond where most professional software developers are today
  • Build an exciting final project that you can add to your portfolio!
